Snap

A student sees a running faucet, lights on in an empty room, an overflowing bin. One tap, one photo. No account, no form.

Bobcat looks

Amazon Bedrock reads the photo and writes the facilities report: category, severity, impact, suggested fix, and a repair cost. About one second.

3
🛠️

Fix it

The report lands on a public Feed. Staff triage it in a private console: confirm the cost, mark it fixed, watch the tiles move.
