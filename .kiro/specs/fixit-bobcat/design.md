# FixIt Bobcat — Design

## Architecture (3 AWS services + hosting)

```
Phone/browser (React + Vite, Amplify UI-free)
   │
   ├─ 1. upload photo ──────────► Amazon S3 (Amplify Storage, guest write, path photos/*)
   │
   ├─ 2. call analyze(photoKey, building) ──► AWS Lambda (Amplify Function)
   │                                            │  reads photo bytes from S3
   │                                            └─► Amazon Bedrock Converse API (vision model)
   │                                            ◄── strict JSON { category, title, ... }
   │
   └─ 3. create Report ─────────► DynamoDB (Amplify Data / AppSync, public apiKey auth)

Feed view: list Reports (DynamoDB) + getUrl for thumbnails (S3)
```

Region: us-east-2 for everything. Bedrock is called with a cross-region inference profile id (`us.` prefix) so us-east-2 works.

## Project layout

```
amplify/
  backend.ts                  # defineBackend({ data, storage, analyze }) + Bedrock IAM policy on analyze
  data/resource.ts            # Report model + analyze query
  storage/resource.ts         # photos/* guest read+write
  functions/analyze/
    resource.ts               # defineFunction, timeoutSeconds: 60, env MODEL_ID
    handler.ts                # S3 GetObject -> Bedrock Converse -> JSON
src/
  main.tsx
  App.tsx                     # tab bar + <Report/> | <Feed/>
  Report.tsx
  Feed.tsx
  seed.ts                     # 5 fake reports for empty-backend demo
  buildings.ts                # building + category lists
  styles.css
amplify_outputs.json          # generated by `npx ampx sandbox`
```

## Data model (`amplify/data/resource.ts`)

```ts
import { type ClientSchema, a, defineData } from '@aws-amplify/backend';
import { analyze } from '../functions/analyze/resource';

const schema = a.schema({
  Report: a.model({
    photoKey: a.string().required(),
    building: a.string().required(),
    category: a.enum(['WATER', 'ENERGY', 'WASTE', 'DAMAGE', 'OTHER']),
    title: a.string().required(),
    description: a.string(),
    impact: a.string(),          // human string, e.g. "~1,500 gallons/week"
    impactScore: a.integer(),    // 1–10, used for the stat tile
    severity: a.enum(['LOW', 'MEDIUM', 'HIGH']),
    action: a.string(),
    status: a.enum(['OPEN', 'FIXED']),
  }).authorization(allow => [allow.publicApiKey()]),

  AnalysisResult: a.customType({
    category: a.string(),
    title: a.string(),
    description: a.string(),
    impact: a.string(),
    impactScore: a.integer(),
    severity: a.string(),
    action: a.string(),
  }),

  analyze: a.query()
    .arguments({ photoKey: a.string().required(), building: a.string() })
    .returns(a.ref('AnalysisResult'))
    .authorization(allow => [allow.publicApiKey()])
    .handler(a.handler.function(analyze)),
});

export type Schema = ClientSchema<typeof schema>;
export const data = defineData({
  schema,
  authorizationModes: { defaultAuthorizationMode: 'apiKey', apiKeyAuthorizationMode: { expiresInDays: 30 } },
});
```

## Function (`amplify/functions/analyze/`)

`resource.ts`:
```ts
import { defineFunction } from '@aws-amplify/backend';
export const analyze = defineFunction({
  name: 'analyze',
  entry: './handler.ts',
  timeoutSeconds: 60,
  environment: { MODEL_ID: 'us.anthropic.claude-sonnet-4-20250514-v1:0' },
});
```

`handler.ts` (shape — Kiro fills in):
1. Read `photoKey`, `building` from `event.arguments`.
2. `GetObject` from the storage bucket (bucket name via env `FIXIT_BUCKET` set in backend.ts from `backend.storage.resources.bucket.bucketName`). Convert body to `Uint8Array`.
3. Bedrock `ConverseCommand` with one user message: `[ { image: { format: 'jpeg', source: { bytes } } }, { text: PROMPT } ]`. Use `@aws-sdk/client-bedrock-runtime`. `maxTokens: 400, temperature: 0.2`.
4. Extract first `{...}` with a regex, `JSON.parse`. On any failure, return the FALLBACK object below (so the demo never dies).

PROMPT:
```
You are FixIt Bobcat, a campus sustainability assistant for Georgia College & State University.
Look at the photo. It was taken in or near: {building}.
Identify the waste or maintenance problem and respond with ONLY a JSON object, no prose, no markdown:
{"category":"WATER|ENERGY|WASTE|DAMAGE|OTHER",
 "title":"max 8 words",
 "description":"1-2 sentences, plain language, written as a facilities report",
 "impact":"a concrete estimate with a unit, e.g. '~1,500 gallons/week' or '~3 kWh/day'. If unsure, give a rough range.",
 "impactScore":1-10 integer (10 = worst),
 "severity":"LOW|MEDIUM|HIGH",
 "action":"one sentence telling facilities what to do"}
If the photo shows nothing wrong, use category OTHER, severity LOW, impactScore 1, and say so kindly.
```

FALLBACK:
```json
{"category":"OTHER","title":"Possible issue spotted","description":"Bobcat couldn't fully analyze this photo, but a student flagged it. Please take a look.","impact":"Unknown","impactScore":3,"severity":"MEDIUM","action":"Send someone to check."}
```

## backend.ts

```ts
import { defineBackend } from '@aws-amplify/backend';
import { PolicyStatement } from 'aws-cdk-lib/aws-iam';
import { data } from './data/resource';
import { storage } from './storage/resource';
import { analyze } from './functions/analyze/resource';

const backend = defineBackend({ data, storage, analyze });

const fn = backend.analyze.resources.lambda;
fn.addToRolePolicy(new PolicyStatement({
  actions: ['bedrock:InvokeModel', 'bedrock:Converse'],
  resources: ['*'],
}));
backend.storage.resources.bucket.grantRead(fn);
backend.analyze.addEnvironment('FIXIT_BUCKET', backend.storage.resources.bucket.bucketName);
```

## Frontend flow

**Report.tsx**
- State machine: `idle → picked → analyzing → result → submitting → done | error`.
- `uploadData({ path: \`photos/${Date.now()}-${file.name}\`, data: file })` from `aws-amplify/storage`.
- `client.queries.analyze({ photoKey, building })` — wrap in `Promise.race` with a 25 s timeout.
- Result card fields are editable inputs (title, description). "Submit report" → `client.models.Report.create({...})`.

**Feed.tsx**
- On mount: `client.models.Report.list()` then sort by `createdAt` desc. If the call throws or returns empty AND `import.meta.env.VITE_DEMO === 'true'`, show `seed.ts` reports instead.
- Thumbnails: `getUrl({ path: photoKey })` per card (fine for < 50 cards).
- "Mark fixed": `client.models.Report.update({ id, status: 'FIXED' })` then update local state.

**App.tsx** — header (bobcat emoji + "FixIt Bobcat" + tagline), tab bar (Report / Feed), content.

## Visual design
- Background off-white `#F7F5EF`, header navy `#0A2240` with gold `#C9A227` title text.
- Cards: white, 16 px radius, soft shadow, 16 px padding.
- Chips: category (navy outline), severity (green/amber/red fill at 15% opacity), status Fixed (green).
- Primary button: full-width, gold background, navy text, 52 px tall, bold.
- Loading: a pulsing 🐾 with "Bobcat is looking…".
- Everything inside a `max-width: 480px; margin: 0 auto` container.

## Fallbacks (use when a step is stuck > 5 min)
| Stuck on | Fallback |
|---|---|
| Bedrock access denied for Claude | Set `MODEL_ID=us.amazon.nova-lite-v1:0` (Nova Lite is usually enabled by default). Change nothing else. |
| S3 upload / Storage permissions | Skip S3: resize image client-side to ≤ 800 px with a canvas, send base64 string as the `photoKey` argument, Lambda decodes it. Store the data URL in `photoKey` (ugly but works). |
| `ampx sandbox` won't deploy | Run the app with `VITE_DEMO=true`, show seed reports on Feed, and call Bedrock from a tiny local Node script via `aws` CLI creds for the live demo. |
| Lambda timeout | Lower `maxTokens` to 250, resize image client-side before upload. |
| Everything is on fire at minute 60 | Freeze the backend. Demo Report → result using a hard-coded analysis for the 3 demo photos keyed by filename. Nobody will know. |
